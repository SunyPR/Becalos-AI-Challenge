# Becalos AI Challenge

Repositorio personal para almacenar proyectos, notas de clase y tareas del programa **Becalos AI Challenge (DEV.F)**.

## Estructura

- `Clases en vivo/` — Apuntes y material de las sesiones en vivo.
- `Fundamentos de IA/` — Notas, ejercicios y proyectos del módulo de Fundamentos de IA.
- `scripts/auto_sync.sh` — Script de sincronización automática con GitHub.
